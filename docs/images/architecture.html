4 · Orchestrator

One briefing, ~8 scode + LLM

1Authorize viewer and client
2Gather facts, compute key figures and exhibits; stream them
3Retrieve per section: filters, then BM25 + vectors fused
4Evidence pack E1..En, 6k tokens, documents fenced as untrusted
5Write 7 sections in parallel, cited inline
6Verify: IDs exist, numbers match, quotes located, injection cap
7Judge: do the sources support the claim?
8Assemble: conflicts, gaps, actions, backstop
5 · API and workspace

FastAPIcode

REST + server-sent events: figures, exhibits, then each section as it is verified. Re-checks access on every source and saved briefing.

React workspaceUI

  • Home: meetings, companies, facilities

  • Attention: overdue first, was → now conflicts, gaps

  • Review: accept / reject with reason
  • After the meeting: notes to commitments
